## keko_enh_compat
Compatibility for [3den Enhanced](https://steamcommunity.com/sharedfiles/filedetails/?id=623475643). Holds everything that reaches into 3den Enhanced: the garrison tool registered under its `Enh` function tag, the faction config export in the 3DEN context menu, and the removal of its buggy `Enh_DoStop` attribute. Skipped automatically when the mod is not loaded.
